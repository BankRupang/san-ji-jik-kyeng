수행 경과 — 트러블 슈팅
01 · Redisson 의존성
redisTemplate.expire() StackOverflowError — 경매 종료 스케줄러 미동작
상황 / 문제
redisTemplate.expire() 호출 시 StackOverflowError 발생 — 경매 Hash는 저장되나 TTL 미설정
auction:endings ZSet 추가 라인도 실행되지 않아 경매 종료 스케줄러 미동작
경매가 종료되지 않고 무한 유지 — 낙찰 불가 상황 초래
원인 분석
redisson-spring-boot-starter가 내부적으로 LettuceConnectionFactory를 RedissonConnectionFactory로 교체.
RedissonConnection.keyCommands()가 this를 반환하므로 pExpire() 호출 시 keyCommands().pExpire() → this.pExpire() → 무한 재귀 → StackOverflow
Before — StackOverflow 발생
BidService
→
redisTemplate.expire()
↓ RedissonConnectionFactory 개입
keyCommands().pExpire()
→
this.pExpire()
→
∞ 재귀
💥 StackOverflowError → TTL 미설정 → ZSet 미추가 → 스케줄러 미동작
After — 정상 동작
BidService
→
redisTemplate.expire()
→
LettuceConnection (정상)
✅ redisson-spring-boot-starter → redisson 교체
LettuceConnectionFactory 유지 → TTL 정상 설정 → ZSet 추가 → 스케줄러 복구
